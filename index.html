Data safety

Backup

A copy of every record, kept off this device

The Supabase project is on the Free plan, which keeps no automated backups. This device and the server hold the same data one sync apart — neither is a backup of the other. Keep the exported file somewhere else.

Inspection archive

Reports and photos written to an external drive

Each inspection is written to the drive as its PDF report plus the original photos. Photos are removed from cloud storage once that archive is over 180 days old — but only after every archived file is re-checked on the drive first, so a missing or disconnected drive never causes a deletion. After a purge the drive is the only copy: keep it somewhere safe.
